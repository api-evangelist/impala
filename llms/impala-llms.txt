# Impala Hotel Booking API

> Impala offered a single, standardized REST API to search, book, and manage hotel rooms across property management systems (PMS) — "the API of the hotel industry." A Speedinvest / Lakestar / Kima Ventures-backed startup (London, founded 2016), it let apps sell rooms and earn commission per booking. The company is defunct: getimpala.com / impala.travel and the API and docs hosts no longer resolve. This profile preserves the historical OpenAPI (apis.guru impala.travel:hotels 1.003) and derived artifacts for reference.

## Specs
- [OpenAPI 3.0 (Impala Hotel Booking API 1.003)](openapi/impala-hotels-openapi-original.json): 10 operations across hotels, rate plans, and bookings.
